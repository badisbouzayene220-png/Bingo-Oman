BINGO Oman — Interactive Categories

Added a dedicated interactive category grid under the Oman destination cards.
Every card is a real link to its destination page:
- Vehicles -> marketplace.html?category=vehicles
- Property -> marketplace.html?category=property
- Electronics -> marketplace.html?category=electronics
- Fashion -> marketplace.html?category=fashion
- Services -> marketplace.html?category=services
- Auctions -> auctions.html
- Tenders -> tenders.html
- Store -> store.html

Cards support Arabic/English labels using the existing language state.
The click interaction includes a subtle press animation.
