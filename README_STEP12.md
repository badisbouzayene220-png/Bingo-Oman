# BINGO Oman ERP - Step 12 Expenses

This step activates and validates the company expense module already included in the ERP.

Features:
- Expense categories
- Vendor name
- Expense date
- Net amount
- VAT rate and VAT amount
- Total including VAT
- Payment method
- Reference and notes
- Expense listing and Excel export
- VAT input tax included in VAT summary
- Expenses included in Profit & Loss

The database objects are created by setup_erp.sql. If Step 11 was already installed successfully, no additional SQL migration is required.
