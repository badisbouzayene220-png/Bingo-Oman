BINGO Oman — Bilingual Project

Arabic and English are supported across the project using language.js.
The selected language is persisted in localStorage:
- bingo-language
- bingo-lang

Destination information pages use dedicated Arabic/English content and automatically
switch direction between RTL and LTR.

Place pages:
place.html?place=muscat
place.html?place=nizwa
place.html?place=salalah
place.html?place=sur
place.html?place=jabal-akhdar

Official/trusted sources are linked on each destination page.
