# BINGO Oman

Bilingual Arabic + English marketplace prototype with 3D-style UI.

## GitHub Pages
1. Upload ALL files in this folder to your GitHub repository root.
2. GitHub Pages will automatically use `index.html`.
3. Open the GitHub Pages URL.

Files:
- `index.html` — English homepage
- `ar.html` — Arabic homepage
- `style.css` — shared design
- `bingo-logo.png` — BINGO logo
- `favicon.png` — favicon
- `404.html` — fallback page

This is a front-end prototype. Real authentication, database, chat, payments, live auctions and tender bidding require backend services.
