# تحديث إدارة الموردين

تمت إضافة داخل ERP:

- إجمالي المشتريات لكل مورد.
- إجمالي المدفوع لكل مورد.
- المتبقي على المورد.
- حالة المورد: نشط / معطل.
- زر تعطيل/تفعيل.
- زر حذف آمن.

## الحذف الآمن
إذا كان المورد مرتبطًا بأي مشتريات أو دفعات، لن يسمح النظام بالحذف النهائي، وسيطلب استخدام **تعطيل المورد** بدلًا من الحذف حتى لا تتأثر السجلات المالية.

## SQL
بعد تشغيل `setup_finance_expansion.sql` شغّل:

`setup_supplier_management_upgrade.sql`

إذا كنت ستشغّل `setup_finance_expansion.sql` من جديد، فقد تم تضمين التعديلات الجديدة فيه أيضًا.
