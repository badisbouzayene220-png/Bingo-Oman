# BINGO Oman — Store & Dynamic Offers

## Added
- Dedicated `store.html` for official store products.
- Products are loaded dynamically from `store_products`.
- Admin Center → Products can create, edit, hide and delete products.
- Home page now has a dynamic Featured Offers area.
- Admin Center → Company Ads controls the offers shown in `home_top`.
- Marketplace continues to show `marketplace_top` ads.

## Database
Run `setup_store.sql` once in Supabase SQL Editor after the existing BINGO admin setup.

## Ads
Use Admin Center → Company Ads:
- `Home top` = homepage Featured Offers
- `Marketplace top` = marketplace banner area
- Publish/Pause/Draft and schedule dates as needed.
