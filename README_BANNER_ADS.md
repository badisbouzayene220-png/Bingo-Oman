# BINGO Oman Top Banner Ads

The Store page now supports full-width Amazon/Noon-style promotional banners with images or videos.

## Admin
Open **Admin Center → Top Banners** to:
- Upload image/video (max 25 MB)
- Add headline, subtitle and CTA button
- Add destination URL
- Publish, pause or save as draft
- Schedule start/end dates
- Set display order

## Store behavior
- Full-width responsive banner
- Auto-rotates every 6 seconds
- Previous/next arrows and dots
- Swipe support on mobile
- Pauses while mouse is over the banner
- Videos autoplay muted and loop
- CTA opens the configured destination

Run `setup_banner_ads.sql` once in Supabase SQL Editor before using the feature.
